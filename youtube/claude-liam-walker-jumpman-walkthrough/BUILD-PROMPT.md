# BUILD-PROMPT — the B00 reconstruction

The film opens on a `ClaudeComposerAsk` card showing the prompt below.

> **This is an illustrative reconstruction, and the film labels it as one.**
> It is not a transcript. The real project was built across many sessions of
> conversation, one bounded change at a time, and no single prompt like this was
> ever sent. It is shown because it states the design ask in one place, which is
> what the opening beat is for. No live build output, progress bar or receipt is
> shown or implied.

```text
Please use Walker to convert my game design document about a world where
gravity has failed — where debris falls upward instead of down, and where the
player finds an object that lets them fall upward too — into a playable Godot
project.

The chapter should run on one rule: the world shows you what you expect, not
what is actually there. Some floors exist but are never drawn. Some are drawn
but are not there. The player checks by turning gravity upside down.
```

## What was actually asked for, over time

Traceable in `CHANGE-BRIEF.md` (five appended revisions) and `FRICTIONAL.md`:

1. A character built from the mechanic rather than a costume swap — the first
   set of themed avatars was rejected.
2. A 3D version with selectable camera POV — **refused**, with reasons, because
   the starter's pixel-space tuning cannot survive the unit change and the
   assignment requires that tuning preserved.
3. A story and theme, after the first extension was judged to be "a competent
   platformer level and nothing more".
4. INVERSION as the central theme, with hidden floors and the Betrayal.
5. Light-when-upright, dark-when-inverted.
6. A rechargeable ability instead of scarce charges.
7. Plain language throughout, after the writing was judged unreadable at speed.
8. Environmental clues instead of prompts.
